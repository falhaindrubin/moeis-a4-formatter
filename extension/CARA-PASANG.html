Sekali sahaja Pasang

  1. Extract fail zip

    Klik kanan fail zip → Extract All… → pilih folder Documents → Extract. Jangan padam folder ini selepas pasang.

    🗜️.zip→📁MOEIS-A4-Formatter

  2. Buka halaman extension

    Di Chrome, taip chrome://extensions pada bar alamat dan tekan Enter. Di Edge, taip edge://extensions.

    chrome://extensions
    Extensions

  3. Hidupkan "Developer mode"

    Klik suis Developer mode di penjuru kanan atas sehingga ia bertukar biru. Di Edge, suis ini ada di sebelah kiri bawah.

    chrome://extensions
    ExtensionsDeveloper mode

  4. Klik "Load unpacked"

    Butang baharu muncul di kiri atas. Klik Load unpacked, buka folder Documents → MOEIS-A4-Formatter, kemudian klik Select Folder.

    chrome://extensions
    Load unpackedPack extension

  5. Siap! Semak kad extension

    Kad MOEIS A4 Formatter muncul dengan suis biru (hidup). Pilihan: klik ikon kepingan puzzle 🧩 di toolbar dan klik pin supaya ikonnya sentiasa kelihatan.

    MOEIS A4 Formatter
    1.2.4
Amaran "developer mode" semasa Chrome dibuka? Ini perkara biasa untuk extension yang dipasang sendiri. Klik pangkah (×) untuk tutup. Jangan klik "Turn off" atau "Remove".

Setiap kali Guna

  1. Buka laporan di MOEIS

    Log masuk MOEIS seperti biasa, kemudian buka Laporan PBD, Laporan Kemahiran BM/BI atau Slip Peperiksaan untuk kelas anda. Jika tetingkap cetak terus muncul, halaman sudah diformat secara automatik. Teruskan ke langkah 4.

    moeissppb.moe.gov.my/laporan/pbd/…
    Laporan PBDSenarai murid kelas…

  2. Klik butang biru "📄 Format A4"

    Butang ini ada di penjuru kanan bawah skrin. Anda juga boleh klik ikon extension di toolbar.

    moeissppb.moe.gov.my/laporan/…
    Laporan murid…📄 Format A4

  3. Semak paparan A4

    Setiap murid kini dipaparkan sebagai sehelai kertas A4 putih. Tatal ke bawah untuk menyemak semua murid.

  4. Klik "🖨️ Cetak (Ctrl+P)"

    Pilih pencetak, atau Save as PDF untuk simpan. Pastikan saiz kertas A4 dan susun atur Portrait. Tetapan lain tidak perlu diubah.

  5. Mahu paparan asal MOEIS?

    Klik butang kelabu ↩️ Paparan Asal di atas butang Cetak. Muat semula biasa (F5) akan memformat semula secara automatik.

    ↩️ Paparan Asal🖨️ Cetak (Ctrl+P)

Versi baharu Kemas kini

  1. Extract zip baharu ke folder yang sama

    Pilih folder Documents\MOEIS-A4-Formatter yang sedia ada dan pilih Replace (gantikan) semua fail.

  2. Muat semula extension

    Buka chrome://extensions dan klik butang anak panah bulat ↻ pada kad MOEIS A4 Formatter.

  3. Semak nombor versi

    Nombor pada kad mesti sudah bertukar kepada versi baharu.

Masalah biasa

Butang "📄 Format A4" tidak muncul

Pastikan anda berada di halaman laporan (alamat bermula dengan moeissppb.moe.gov.my/laporan/) dan suis extension di chrome://extensions berwarna biru. Tekan F5 untuk muat semula halaman.

Keluar "Format halaman ini tidak dikenali"

Jenis laporan itu belum disokong. Hanya Laporan PBD, Laporan Kemahiran BM/BI dan Slip Peperiksaan disokong buat masa ini. Cetak seperti biasa dari MOEIS.

Extension hilang selepas komputer dibuka semula

Folder MOEIS-A4-Formatter mungkin telah dipadam atau dipindahkan. Extract semula zip ke Documents dan ulang langkah pasang 4 (Load unpacked).

Tulisan terpotong di bawah muka surat

Pastikan anda menggunakan versi terkini (1.2.4 atau lebih baharu). Di tetingkap cetak, pastikan Paper size A4 dan Scale "Default".

Keselamatan & data murid

🔒 Tiada data dihantar

Extension hanya menyusun semula paparan di komputer anda. Ia tidak membaca, menyimpan atau menghantar maklumat murid.

🎯 Aktif di MOEIS sahaja

Hanya berfungsi di halaman moeissppb.moe.gov.my/laporan/. Tiada kebenaran khas diminta.

📄 Jaga PDF (PDPA)

PDF slip dan laporan mengandungi No. KP murid. Kongsi dengan berhati-hati dan padam salinan yang tidak diperlukan.

✅ Sumber dipercayai

Dapatkan fail zip hanya daripada pembuatnya sendiri. Jangan pasang salinan daripada orang yang tidak dikenali.
